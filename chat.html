How does the dashboard authenticate against the payments API?
The dashboard attaches a JWT to every outgoing request, and the API verifies it in a middleware before any route handler runs.
web-dashboard · src/api/client.ts 
client.interceptors.request.use((cfg) => {
  cfg.headers.Authorization = 'Bearer ' + token;
  return cfg;
});

On the API side, requireAuth reads that header and calls jwt.verify before attaching the user to the request.
